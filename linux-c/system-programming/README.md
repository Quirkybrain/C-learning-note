# Linux 系统编程学习笔记

这个目录记录在 Linux 用户空间中使用 C 语言进行系统编程的学习过程。

内容会围绕文件描述符、进程、信号、内存映射、进程间通信和网络 I/O 等主题展开。每篇笔记会尽量保持“一个核心问题 + 一份可运行示例”，先建立主要概念，再逐步补充更完整的错误处理和工程细节。

## 系列定位

这个系列主要关注：

- Linux 用户空间程序如何通过系统接口请求内核服务。
- 文件描述符如何连接文件、终端、管道和 Socket。
- 进程、内存、信号和 I/O 状态如何随调用发生变化。
- 程序获得的内核资源应该如何使用和释放。

这里的示例优先讲清主要调用链，再在后续笔记中逐步增加错误处理和更完整的工程写法。

## 学习路线

这个系列会从最基础的文件 I/O 出发，逐步进入其他 Linux 系统编程主题：

```text
文件与文件描述符
    ↓
进程、管道与信号
    ↓
内存映射与进程间通信
    ↓
Socket 与 I/O 多路复用
```

## 当前内容

### 001：基础文件 I/O

[阅读笔记：001-basic-file-io](./001-basic-file-io/README.md)

这一章通过一条最小的 Linux 文件 I/O 链路：

```text
open -> write -> lseek -> read -> close
```

建立以下概念：

- 用文件描述符表示已打开的文件。
- 通过明确的字节数读写数据。
- 理解 `write()` 和 `read()` 对文件偏移量的影响。
- 用 `lseek()` 显式调整文件偏移量。
- 区分原始字节序列和以 `\0` 结尾的 C 字符串。
- 理解标准输入、标准输出和标准错误也是文件描述符。
## 构建与运行

每篇笔记使用独立目录，通常包含：

```text
NNN-topic-name
├── README.md   # 概念、推导过程与运行结果
├── Makefile    # 构建脚本
└── src         # 示例源代码
```

当一个示例只有一个源文件时，目录会尽量保持简单；当内容需要拆成多个模块时，再增加 `include/` 和更完整的 `src/` 结构。

进入某篇笔记的目录后，通常可以执行：

```bash
make
make run
make clean
```

## 阅读方式

阅读这些示例时，可以重点观察四件事：

1. 系统接口接收什么参数。
2. 成功时返回什么，失败时如何表示。
3. 调用完成后，进程或内核中的哪些状态发生了变化。
4. 获得的资源最后由谁释放。

除了阅读源代码，还可以配合下面的工具：

```bash
man 2 read
man 2 fork
man 2 mmap
strace ./program
```

`man 2` 可以查看系统接口文档，`strace` 则可以观察程序运行时实际进入了哪些 Linux 系统调用。

## 这个系列的边界

这些代码用于学习和演示，会优先保证主要调用链清晰，而不会一开始就展开所有工程化处理。

例如，基础文件 I/O 示例暂时不处理短读、短写、`EINTR`、完整错误信息和数据同步等问题。这些内容会随着学习深入逐步加入，不影响当前示例要表达的核心概念。

这个系列的目标可以概括为：

> 通过一组小而可运行的 C 程序，逐步理解 Linux 如何组织文件、进程、内存、通信与 I/O。

## 后续方向

在当前基础文件 I/O 的基础上，后续可以继续学习：

- `stat()` / `fstat()` 与文件元数据。
- `dup2()` 与标准输入输出重定向。
- `pipe()`、`fork()`、`execve()` 与进程协作。
- `sigaction()` 与信号处理。
- `mmap()` 与文件映射。
- Socket 和 `poll()` / `epoll()` 网络 I/O。
